📖 Executive Summary & Abstract
Formal Abstract
Debates surrounding the Indus Valley sign system (c. 2600–1900 BCE) remain unresolved due to inscription brevity (average length: 4.4–5.6 signs) and the absence of bilingual monuments. This repository provides an open-source analytical framework evaluating positional Shannon information entropy ($H$) and first-order Markov transitions on 5-sign Harappan inscriptions.
Using the standardized 5-sign deduplicated sub-corpus ($N = 1,916$ texts, $11,110$ tokens, $584$ unique sign types) derived from the ICIT / Yajnadevam digitization project as compiled by Nair (2026), we quantify a statistically significant localized drop in information entropy at the penultimate position (Slot 4: $H_4 = 3.77$ bits, compared to unconstrained merchant ID slots $H_2 = 4.44$ and $H_3 = 4.45$ bits; Friedman test $\chi^2(4) = 14.7, p = 0.005$).
This positional constraint aligns with functional commodity-limit markers (such as numerical stroke groups I, II, III), offering quantitative support for the hypothesis that Indus inscriptions served primarily as asynchronous administrative transaction ledgers rather than alphabetic/syllabic spoken prose.
ELI5 (Explain Like I'm 5)
Imagine ancient Indus seals as Bronze Age transactional receipts or security tokens. The first sign indicates the issuing authority/region, the middle signs represent a unique merchant/account number, and the 4th slot acts as a credit limit or batch size marker (e.g., "2 units of copper" or "3 bales of cotton"). This repository provides the mathematical code proving that Slot 4 has strict rules that match accounting ledgers rather than spoken language grammar.

📊 Benchmark Statistical Results
Inscription Slot	Positional Function	Positional Shannon Entropy $H(X)$	Empirical Target
Slot 1 (Right)	Issuer / Administrative Prefix	3.13 bits	Low Entropy
Slot 2	Merchant ID / Account Registration 1	4.44 bits	Max Unconstrained
Slot 3	Merchant ID / Account Registration 2	4.45 bits	Max Unconstrained
Slot 4 (Penultimate)	Transaction / Commodity Limit Field	3.77 bits	Localized Dip
Slot 5 (Left Terminal)	Terminal Commodity / Signatory Marker	3.98 bits	Moderate Entropy
Statistical Significance: Friedman non-parametric test across positional distributions yields $\chi^2(4) = 14.7, p = 0.005$, confirming that the entropy reduction in Slot 4 is statistically significant and non-random.

🚀 How to Run the Analysis
Prerequisites
Make sure you have Python 3.10+ installed along with the required scientific packages:
```bash
pip install numpy pandas scipy matplotlib
```
Running the Script
Clone the repository and execute the analysis pipeline:
```bash
git clone https://github.com/Igor-Krasner/Indus-Script-Pri-Krasner-Analysis.git
cd Indus-Script-Pri-Krasner-Analysis
python indus_analysis.py
```
Running the script will:
Construct the benchmark positional dataset ($N = 1,916$).
Compute Shannon entropy values for each slot.
Perform the Friedman non-parametric significance test.
Export the high-resolution visualization `positional_entropy_profile.png`.
